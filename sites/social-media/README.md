# Social Media Playbooks

Playbooks for browser-based agents working with social platforms through their normal web UIs.

## Candidate Sites

- LinkedIn
- Instagram
- Facebook
- X / Twitter
- Reddit
- TikTok

## Useful Workflow Types

- Search and profile discovery
- Drafting posts or comments without publishing
- Reading notifications or inbox context
- Extracting visible public profile details
- Preparing outbound messages for user review

## Boundaries

Publishing, commenting, reacting, following, unfollowing, messaging, deleting, changing privacy settings, or uploading media should require explicit user confirmation.
