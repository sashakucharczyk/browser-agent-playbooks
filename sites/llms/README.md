# LLM Web App Playbooks

Playbooks for browser-based agents using LLM web apps through signed-in browser sessions.

## Candidate Sites

- ChatGPT
- Claude
- Gemini
- Perplexity
- Grok

## Useful Workflow Types

- Start a new chat
- Send a prompt
- Attach a file when the user has approved it
- Read the latest model reply
- Detect when generation has finished
- Compare outputs across multiple LLM web apps

## Notes

Playbooks should document model selectors, composer labels, submit controls, response regions, generation-complete signals, and account-plan differences when visible.
