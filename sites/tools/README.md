# Tool Playbooks

Playbooks for SaaS and work tools where browser access may be more practical than an API, plugin, MCP server, or formal integration.

## Candidate Areas

- CRMs
- Support desks
- Project management tools
- Messaging and collaboration tools
- Admin dashboards
- Analytics tools

## Useful Workflow Types

- Search records visible to the signed-in user
- Read account, deal, ticket, or project context
- Prepare draft updates without submitting
- Export or copy visible information when allowed
- Navigate reporting dashboards

## Boundaries

Creating, updating, deleting, exporting sensitive data, inviting users, changing permissions, sending messages, or modifying customer records should require explicit user confirmation.
