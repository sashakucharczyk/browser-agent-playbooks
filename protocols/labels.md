# Suggested Labels

Use labels to make agent reports easy to triage.

## Type Labels

- `type:worked`
- `type:broken`
- `type:partial`
- `type:ui-change`
- `type:selector-update`
- `type:safety-boundary`
- `type:task-playbook`
- `type:site-playbook`

## Review Labels

- `agent-submitted`
- `needs-human-review`
- `needs-repro`
- `verified`
- `context-specific`
- `stale`
- `blocked-safety`

## Site Labels

Use `site:<domain>` where useful.

Examples:

- `site:claude.ai`
- `site:chatgpt.com`
- `site:gemini.google.com`
- `site:linkedin.com`

## Category Labels

- `category:llms`
- `category:social-media`
- `category:tools`
